# Paxos-Odin 0.1.0 Release Notes

**Release Date:** 2026-09-16

We are proud to announce the initial release of **Paxos-Odin**: an idiomatic, pure, bounded implementation of Classic and Multi-Paxos written in Odin.

## Highlights

- **Zero-I/O Pure State Machine**: Owns no sockets, threads, clocks, or dynamic heap allocations.
- **Explicit Effects Architecture**: Every state transition consumes events and writes outputs to caller-owned `Effects` buffers.
- **Enforced Durability Contract**: Runtime gate guarantees that `Effects.writes` are persisted to stable storage before `Effects.messages` can be transmitted over the network.
- **Reconfigurable Command Log**: Implements Lamport's Stop Signs, allowing atomic configuration transitions and epoch sealing for snapshot handovers.
- **Contiguous Non-Voting Learners**: Sliding ring-buffer window buffers out-of-order commits and releases only strictly contiguous chosen values.
- **Deterministic Chaos Simulator**: Seed-driven simulator with packet drop, duplicate, partition, crash, and restart fault injection verified against a central golden oracle.
- **In-Memory Benchmark Suite**: Validating >1.5M proposals/sec in-memory with sub-microsecond transition latency.
- **POD (Paxos Odin Discussions) RFC System**: Built-in RFC process and Typst documentation pipeline modeled after `zenfmt`.
- **Unified Toolchain CLI (`paxos-cli`)**: Managing builds, unit tests, chaos simulations, benchmarks, and Typst documentation generation.
